# Notes for Claude

This is the **public** repository of Swipe Scout. It contains **no source code** – the code lives in the private
repository **hyperflux22/Bilder**. Owner's language: German.

## On EVERY update (owner's rule)

- Put only the **standard** variant (with GitHub link) here as `versions/<x.y>/SwipeScout.apk`.
  Never the `privat` variant, never source code, keystore, build files or tests.
- Update `README.md` / `README.de.md` (version badge, versions table), `CHANGELOG.md` / `CHANGELOG.de.md`,
  `docs/screenshots/`, banners and icon from the private repository.
- Merge via pull request into `main`; the “Publish releases” workflow creates release `v<x.y>` (newest = latest).
- Versioning: big change → first number (3.1 → 4.0), small change → second number (3.1 → 3.2).
